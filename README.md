The official asset repository for **RiiSync**. This database provides high-quality, animated Wii System Menu icons used in the still, unreleased, Android application.

---

## 📂 Repository Structure

The database is organized logically by **4-character Wii Game IDs** (e.g., `SMNE`, `RMCP`).

```text
database/
├── [GAME_ID]/
│   └── icon_animated.png   # Authentic Wii Channel animation
└── WiiSave-Database.json   # Metadata and mapping file (Optional)
